Backend

backend/__init__.py
Marks the backend folder as a Python package so package-style imports work on Vercel and other environments.

backend/app.py
Main Flask entrypoint. Creates the app, sets the frontend static folder, and registers all routes.

backend/routes.py
All HTTP routes live here.
- /
- /upload
- /mapping/preview
- /health
- /config
- /set_mode

backend/config.py
Central runtime config.
Contains:
- thresholds
- weights
- VPN / IP ranges
- mapping confidence threshold
- chunk size and memory settings

backend/csv_reader.py
Reads CSV files with Polars, including chunked loading for large files.

backend/schema_mapper.py
Maps uploaded CSV columns into the internal schema.
Main responsibility:
- detect known templates
- heuristic / fuzzy mapping
- build mapping report
- output standardised dataframe

backend/utils.py
Shared helper functions.
Contains:
- IP reputation checks
- device category detection
- email risk analysis
- timestamp normalisation

backend/fraud_detector.py
Core fraud analysis engine.
Contains:
- preprocessing
- card testing detection
- account takeover detection
- BIN attack detection
- device anomaly detection
- clustering
- risk scoring
- final analysis payload

Quick debugging guide

If the page loads but looks broken:
Check frontend/styles/index.css

If navigation or buttons do nothing:
Check frontend/js/app.js

If upload fails:
Check frontend/js/upload.js and backend/routes.py

If schema mapping looks wrong:
Check backend/schema_mapper.py

If fraud flags look wrong:
Check backend/fraud_detector.py

If charts do not appear:
Check frontend/js/analytics.js

If maps do not appear:
Check frontend/js/ip_intel.js

If a specific page is broken:
Find the matching file in frontend/js/ with the same feature name
